# Food Recipes

A simple website containing a collection of delicious food recipes.

This project was created to practice the fundamentals of HTML and learn the basics of working with Git and GitHub.

## What I Learned

While building this project, I learned how to:

- Create and edit HTML files
- Use headings, paragraphs, and basic text styling
- Link pages and files together
- Add and use images in a webpage
- Create ordered and unordered lists
- Structure content using HTML elements
- Use the basic Git workflow
  - `git add`
  - `git commit`
  - `git push`

## Recipes

The website currently contains recipes such as:

- Pizza
- Cheeseburger
- Lasagna

More recipes may be added as the project develops.

## Technologies Used

- HTML
- Git
